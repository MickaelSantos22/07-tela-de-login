# 📝 Registration Form

Formulário de cadastro desenvolvido com **HTML5 e CSS3**, com foco em responsividade, organização de elementos e boas práticas de desenvolvimento Front-End.

O projeto apresenta uma interface moderna, com campos de preenchimento organizados em duas colunas e adaptação para dispositivos móveis.

## 🎨 Preview

[https://prnt.sc/XF0dTLeXN4tn]

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Formulário de cadastro.
- Campos para nome, usuário, e-mail, telefone e senha.
- Confirmação de senha.
- Seleção de gênero com Radio Buttons.
- Destaque visual nos campos durante o foco.
- Layout responsivo para diferentes tamanhos de tela.

## 📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes dispositivos:

- **Desktop:** formulário organizado em duas colunas.
- **Tablet:** adaptação dos espaçamentos e distribuição dos elementos.
- **Mobile:** campos reorganizados em uma única coluna.

## 📚 Conceitos praticados

Durante o desenvolvimento, foram aplicados conceitos importantes de HTML e CSS:

- CSS Grid para organização dos campos.
- Flexbox para alinhamento dos elementos.
- Media Queries para responsividade.
- `clamp()` para dimensionamento flexível.
- `minmax()` para controle das colunas do Grid.
- `grid-column` para posicionamento dos elementos.
- `accent-color` para personalização dos Radio Buttons.
- Pseudo-elementos (`::after`).
- Estados de interação (`:hover` e `:focus`).
- Variáveis CSS e organização de estilos.
